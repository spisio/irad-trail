The Irad Trail

Spring 1877. Kokand has fallen and settlers hold your clan's pastures on the Chu. Lead the family 690 versts by horse caravan, over three high passes and four rivers, to the Church of St. Janyl at Iyık Janyl. Get there before the snow closes the Ala-Bel.

Play it on an emulator

The same BASIC listing that runs above also runs on a Commodore 64. Use the disk image (irad-trail.d64) or the program file (irad-trail.prg) with an emulator such as VICE.

  1. Start VICE's C64 emulator (x64sc).
  2. Choose File → Smart attach, then pick irad-trail.d64. Most emulators also run the file if you drag it onto the window.
  3. If it does not start by itself, type LOAD"*",8, press Return, then type RUN.
